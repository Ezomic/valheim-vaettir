# Vaettir: a turnip planted beside a carrot bed continues the carrots' rows.
#
# LHM-29. The grid used to read rows only off plants of the SAME crop, so the first turnip beside
# a carrot bed found none and started a grid of its own. That is the other way one field came out
# on two grids. Now any standing plant spaced alike counts, and carrots and turnips both step a
# metre.
#
# The carrot bed is four carrots put down with `mod furrowtest free`, exactly where each is put
# and on no grid: a bed from before this fix, or one planted by hand with Shift held, which a step
# cannot do. The bed is also turned 30 degrees against your grid, and that is what makes this hard
# to fool. A turnip that ignored the carrots goes on the shared grid at your own angle, and that
# can never be the bed's rows. A bed square with your grid would sit on the shared grid by chance
# about one run in twenty-five.
#
# The two turnips go in with `build`: the cultivator, the ghost, Furrow's snap and the place
# button. Each is aimed a quarter of a row off the bed's next free spot, so a turnip the grid did
# not move is not in the bed's rows either.
#
# `mod furrowtest forget` at the start lifts a pin and empties what the grid is holding, which is
# the state a freshly started game is in; nothing but a restart does that. `free Oak_Sapling 0 12`
# and `face` turn you along the grid's columns, so `build` measures forward and right in the same
# frame `furrowtest free` places the bed in (metres right, then forward).
#
# What passes: the bed alone "on one grid" with 4, then carrots and turnips "on one grid" with 6.
# What a broken build reads: turnips that ignored the carrots read "on 2 grids (4 + 2)" at two
# angles 30 degrees apart. A grid that is not running reads 3 grids.
#
# Needs: singleplayer, in a test world. GridEnabled on, GridCell 0, Sowing off. Farming is set to
# 50 and put back. The turnips' spots are tilled; the free carrots stand on untilled ground and
# wilt after ten seconds, which does not move them. The level Meadows ground with twenty metres
# clear that this used to ask for is the `stage`'s job now.
#
# The stage after `biome` takes down everything within thirty metres first, the world's own trees,
# rocks and wild plants for good, and levels the ground. Leaves the bed, two turnips, the marker oak
# and two tilled spots behind; the next run plants on fresh ground of its own.

clear
give Cultivator:1,TurnipSeeds:10
skill Farming 50

# Meadows the map has not shown you yet, found rather than promised, because a suite run starts
# wherever the scenario before it left you. In the second 2.3.0 run that was the Deep North,
# inside the Queen's entrance utangard-queen-door-stays-sealed spawns, where tilling was refused
# as snow too deep. Plain `biome Meadows` answered that and missed the next case: already in the
# Meadows, it does not move you. The third run came here straight from Malmr, whose last file
# leaves a copper deposit (rock4_copper_frac) about five metres in front of where you stand, and
# `wipe` took only pieces then (since Devkit 686ff58 it takes what `put` left too). Every `build`
# in the three furrow files that ran stopped on that
# deposit ("last on Rock4_cell ... (not the ground)"), so not one sapling or crop went in and each
# `furrow check` counted only what `furrowtest free` had put down. `fresh` always moves you, to
# ground no scenario has used.
biome Meadows fresh
wait 3

# Cleared and levelled where `fresh` put you: every piece, drop, tree, rock and wild plant within
# thirty metres taken down, and the ground levelled to the height under your feet, so every `build`
# and tilling swing below aims at the same ground. Devkit's automatic stage before the first step
# ran where the file before left you, which `fresh` never is. Before the stage a wild tree or rock
# could still stand here and stop a `build`, which named it the way it named the deposit. This
# replaces the `wipe 20` that stood here: the stage takes down everything it did and more.
stage

mod furrowtest forget
mod furrowtest free Oak_Sapling 0 12
printed off any grid yes
wait 1
face Oak_Sapling 15
wait 1
tool Cultivator

# Tilled before the bed goes down, while nothing stands in the placement ray's way.
# A second after every tilling swing. `build` reads the ground's height the moment it starts,
# and a swing's new ground only reaches the terrain's collider at the end of the frame it lands
# in, which is the frame Devkit starts the next step in. Without the wait the next `build`
# aims at the ground as it stood before the swing and fails "could not put the placement ray
# on the spot". See vaettir-furrow-patches-share-a-grid.
build cultivate_v2 2.98 0.73
wait 1
build cultivate_v2 2.47 0.21
wait 1


# ---- the bed: a one-metre square turned 30 degrees, on your left

mod furrowtest free sapling_carrot -2.2 2.4
mod furrowtest free sapling_carrot -1.334 1.9
mod furrowtest free sapling_carrot -1.7 3.266
mod furrowtest free sapling_carrot -0.834 2.766
wait 1

mod furrow check sapling_carrot 6
printed furrow check: 4 yes
printed on one grid yes


# ---- the turnips, beside it on the right, far one first

build sapling_turnip 2.98 0.73
build sapling_turnip 2.47 0.21
wait 1

mod furrow check sapling_carrot,sapling_turnip 6
printed furrow check: 6 yes
printed rows 1m apart yes
printed on one grid yes

skill Farming back
