# Vaettir: one plant off the grid does not pull the next one out of the bed.
#
# LHM-29. When the grid lost track of a bed it took the NEAREST plant as the start of its rows. If
# that one had been planted by hand, off the grid, everything after it followed it instead of the
# bed, which reads in game as the grid changing for no reason partway through a field. Now the
# plants within reach vote, and the rows most of them sit on win.
#
# So: a bed of four onions, a fifth put down half a row off them both ways, and an onion aimed
# right next to that stray - 0.65m from it and 1.25m from the nearest onion in the bed. It must
# land in the bed's rows.
#
# The bed and the stray go down with `mod furrowtest free`, exactly where each is put. By hand
# that is Shift held, which a step cannot do, and the Farming gate cannot stand in for it because
# GridLevel can be 0. The new onion goes in with `build`: the cultivator, the ghost, Furrow's snap
# and the place button. `mod furrowtest forget` at the start lifts a pin and empties what the grid
# is holding, the state of a freshly started game, which nothing but a restart reaches.
# `free Oak_Sapling 0 12` and `face` turn you along the grid's columns so `build` and
# `furrowtest free` measure in one frame (metres right, then forward).
#
# What passes: before the new onion, "on 2 grids (4 + 1)" - the bed and the stray, proving the
# stray really is off the bed's rows. After it, "on 2 grids (5 + 1)": the bed with the new onion
# in it, and the stray alone.
# What a broken build reads: "on 2 grids (4 + 2)", the new onion having followed the stray. The
# stray is exactly half a row off the bed, so one cannot be mistaken for the other. A grid that
# is not running leaves the new onion where it was aimed, a quarter row off the bed's rows and
# 0.4 off the stray's, and reads "on 3 grids (4 + 1 + 1)".
#
# Needs: singleplayer, level ground in the Meadows with twenty metres clear. GridEnabled on,
# GridCell 0, Sowing off. Farming is set to 50 and put back. Onions are taken to step a metre, and
# the check fails if it prints anything else. Only the new onion's spot is tilled; the free ones
# wilt after ten seconds, which does not move them.
#
# Takes down every piece within 20m first. Leaves six onions, the marker oak and a tilled spot;
# the next run's wipe takes the plants and the oak.

clear
give Cultivator:1,OnionSeeds:5
skill Farming 50

# The Meadows, found rather than promised, because a suite run starts wherever the scenario
# before it left you. On 2026-09-28 that was the Deep North, inside the Queen's entrance
# utangard-queen-door-stays-sealed spawns, and ten Vaettir files failed on the place and not
# on the mod: tilling refused as snow too deep, and the entrance's own pieces, cut through by
# `wipe`, falling and dropping copper scrap. Already in the Meadows, this does not move you.
biome Meadows
wait 3

wipe 20
wait 1

mod furrowtest forget
mod furrowtest free Oak_Sapling 0 12
printed off any grid yes
wait 1
face Oak_Sapling 15
wait 1
tool Cultivator

# Tilled before anything stands in the placement ray's way.
build cultivate_v2 2.35 1.1


# ---- the bed: a row of three, and one a row nearer you at its left end

mod furrowtest free sapling_onion -1 3.6
mod furrowtest free sapling_onion 0 3.6
mod furrowtest free sapling_onion 1 3.6
mod furrowtest free sapling_onion -1 2.6

# The stray, half a row off the bed both ways.
mod furrowtest free sapling_onion 0.5 2.1
wait 1

mod furrow check sapling_onion 8
printed furrow check: 5 yes
printed on 2 grids (4 + 1) yes


# ---- the new onion, aimed beside the stray

build sapling_onion 2.35 1.1
wait 1

mod furrow check sapling_onion 8
printed furrow check: 6 yes
printed rows 1m apart yes
printed on 2 grids (5 + 1) yes

skill Farming back
