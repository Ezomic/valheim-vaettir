# Vaettir: wild mushrooms beside a new bed do not decide its rows.
#
# LHM-29, found in review before it shipped. The grid reads rows off the plants already in the
# ground, grown crops included, and Thicket's mushroom seedling grows into Pickable_Mushroom - the
# same prefab the world scatters wild, and spaced exactly like a carrot. So every wild mushroom in
# reach counted as a carrot bed of one, beat the shared grid, and a bed started next to it took
# that mushroom's rows. Now anything the world spawns by itself is left out.
#
# So: two mushrooms stood on the ground around you, two carrots planted within reach of both,
# and two more carrots nine metres off with nothing near them. All four must be on one grid, the
# shared one.
#
# `grow Pickable_Mushroom 2 3` stands the two mushrooms 4.29m apart, within 0.05 of the diagonal
# of a three-row square. If they counted, they would be a pair in line at 62 degrees, their rows
# would outvote everything else, and the first two carrots would go down turned 62 degrees. The
# far pair lands on the shared grid at your own angle either way. So a broken build shows as an
# angle, every run, and cannot hide in an offset that happens to line up.
#
# That only holds while Thicket's mushroom seedling steps a metre like the carrot; if it did not,
# the mushrooms would never have counted and this would pass for that reason alone. So one
# seedling is put down eight metres behind you with `mod furrowtest free`, which prints its
# spacing - nothing else reports a plant's spacing - and "rows 1m apart" is required. Eight metres
# is well outside the reach of every carrot here.
#
# Every carrot goes in with `build`: the cultivator, the ghost, Furrow's snap and the place
# button. `mod furrowtest forget` at the start lifts a pin and empties what the grid is holding,
# the state of a freshly started game, which nothing but a restart reaches. `free Oak_Sapling 0 12`
# and `face` turn you along the grid's columns, as in the other Furrow files.
#
# What passes: "on one grid" with 4 carrots.
# What a broken build reads: "on 2 grids (2 + 2)" at two angles, one of them 62.
#
# Needs: singleplayer, in a test world, and no other mushroom within six metres. The `count` step
# checks that, because a third one would change what a broken build reads, and the `stage` after
# `biome` sees to it, since it takes every pickable plant within thirty metres down before `grow`
# stands the two this file needs. The level Meadows ground with twenty metres clear that this used
# to ask for is the stage's job now too. Thicket on, with SpacingScale 1. GridEnabled and
# GridShared on, GridCell 0, Sowing off, and a GridAngle other than 62 (or 152). Farming is set to
# 50 and put back.
#
# The stage takes down everything within thirty metres first, the world's own trees, rocks and
# wild plants for good, and levels the ground. Leaves the two mushrooms, the four carrots, the
# seedling and the marker oak behind. The next run plants on fresh ground of its own, and its
# stage would take the two mushrooms down in any case, which `wipe` never could, so they are never
# in its `count`.

clear
give Cultivator:1,CarrotSeeds:10
skill Farming 50

# Meadows the map has not shown you yet, found rather than promised, because a suite run starts
# wherever the scenario before it left you. In the second 2.3.0 run that was the Deep North,
# inside the Queen's entrance utangard-queen-door-stays-sealed spawns, where tilling was refused
# as snow too deep. Plain `biome Meadows` answered that and missed the next case: already in the
# Meadows, it does not move you. The third run came here straight from Malmr, whose last file
# leaves a copper deposit (rock4_copper_frac) about five metres in front of where you stand, and
# `wipe` took only pieces then (since Devkit 686ff58 it takes what `put` left too). Every `build`
# in the three furrow files that ran stopped on that
# deposit ("last on Rock4_cell ... (not the ground)"), so not one sapling or crop went in and each
# `furrow check` counted only what `furrowtest free` had put down. `fresh` always moves you, to
# ground no scenario has used.
biome Meadows fresh
wait 3

# Cleared and levelled where `fresh` put you: every piece, drop, tree, rock and wild plant within
# thirty metres taken down, and the ground levelled to the height under your feet, so every `build`
# and tilling swing below aims at the same ground. Devkit's automatic stage before the first step
# ran where the file before left you, which `fresh` never is. Before the stage a wild tree or rock
# could still stand here and stop a `build`, which named it the way it named the deposit. This
# replaces the `wipe 20` that stood here: the stage takes down everything it did and more.
#
# The wild mushrooms go with it, since the stage takes every pickable plant, and that is safe for
# this file: the two it needs are stood up by `grow` below, after the stage, and the `count` after
# them now has only those two to find.
stage

mod furrowtest forget
mod furrowtest free Oak_Sapling 0 12
printed off any grid yes
wait 1
face Oak_Sapling 15
wait 1
tool Cultivator

# The premise: a mushroom seedling steps a metre, the same as a carrot.
mod furrowtest free thicket_mushroom 0 -8
printed rows 1m apart yes

# Tilled before the mushrooms go up, while nothing stands in the placement ray's way.
# A second after every tilling swing. `build` reads the ground's height the moment it starts,
# and a swing's new ground only reaches the terrain's collider at the end of the frame it lands
# in, which is the frame Devkit starts the next step in. Without the wait the next `build`
# aims at the ground as it stood before the swing and fails "could not put the placement ray
# on the spot". See vaettir-furrow-patches-share-a-grid.
build cultivate_v2 1.1 0.8
wait 1
build cultivate_v2 1.1 -0.85
wait 1

grow Pickable_Mushroom 2 3
count Pickable_Mushroom 2 6
wait 1


# ---- two carrots beside you, within four metres of both mushrooms however you stand

build sapling_carrot 1.1 0.8
build sapling_carrot 1.1 -0.85
wait 1

# Both of them, counted where they stand before anything else goes in. In 2.3.0's fourth run the
# check at the end found 3 carrots where 4 had been planted, all on one grid at 0 degrees, and
# neither log says which one was missing or when it went: all four `build`s placed, Player.log has
# a PlacePiece line for each, and nothing reported destroying one. Four metres reaches these two
# and nothing else this file plants, so a carrot lost beside the mushrooms fails here, one lost
# over there fails at the next count, and a last count short of the two added up is the check.
mod furrow check sapling_carrot 4
printed furrow check: 2 yes


# ---- nine metres to your right, out of reach of the mushrooms and the carrots

move 0 9
build cultivate_v2 1.1 0.8
wait 1
build cultivate_v2 1.1 -0.85
wait 1
build sapling_carrot 1.1 0.8
build sapling_carrot 1.1 -0.85
wait 1

mod furrow check sapling_carrot 4
printed furrow check: 2 yes

mod furrow check sapling_carrot 12
printed furrow check: 4 yes
printed rows 1m apart yes
printed on one grid yes

skill Farming back
