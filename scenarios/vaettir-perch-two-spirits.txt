# Vaettir: a spirit perch puts a second spirit in the air.
#
# Plan steps 24 and 25. The perch is the one upgrade whose whole result is something you
# watch rather than something you can open, so the assertion counts what is actually in the
# scene: ForestSpirit instances near the post.
#
# MatchContents is on by default, which is what makes this work without configuring
# anything: a chest that already holds wood will take more wood. So the chest is seeded with
# one of each kind first, and then the post has somewhere to send things.
#
# Timing is real here rather than instant. A spirit is born, flies, unloads and comes back,
# so the counts are taken while the post still has plenty left to move.
#
# The `stage` after `biome` clears and levels thirty metres round you, so the flat ground, the ten
# metres clear and the distance from other posts and chests this used to ask for are its job now.
# It takes down EVERYTHING built there, and the world's own trees and rocks for good, so run it in
# a test world and never near a real base.

clear
give Hammer:1,Hoe:1
give FineWood:250,BronzeNails:40,IronNails:52,Silver:20,GroveHeartwood:6
give Wood:200,Stone:200,Flint:100
god
ghost

# The Meadows, found rather than promised, because a suite run starts wherever the scenario
# before it left you. On 2026-09-28 that was the Deep North, inside the Queen's entrance
# utangard-queen-door-stays-sealed spawns, and ten Vaettir files failed on the place and not
# on the mod: tilling refused as snow too deep, and the entrance's own pieces, cut through by
# `wipe`, falling and dropping copper scrap. Already in the Meadows, this does not move you.
biome Meadows
wait 3

# Cleared and levelled where `biome` left you: every piece, drop, tree and rock within thirty
# metres taken down, so the `ground 0` at the end counts only what this file dropped, and the
# ground levelled to the height under your feet. Devkit's automatic stage before the first step ran
# where the file before left you, which is not here when `biome` moved you. It replaces the `sweep`
# and `wipe 16` that stood here, doing both over more ground.
stage

place stow_post 4 0
wait 6

place piece_chest_wood 6 3
wait 2
stock piece_chest_wood Wood:1,Stone:1,Flint:1

# One spirit before the perch is built.
stock stow_post Wood:150,Stone:150,Flint:90
wait 2
count stow_carrier 1

wait 6

place stow_perch 4 2
wait 3
hover stow_perch two_spirits

# Keep it loaded, so there is still work to hand out.
stock stow_post Wood:50,Stone:50
wait 3
count stow_carrier 2

# And nothing was dropped on the way. Asserting a stack count here was wrong: a hundred
# and fifty wood arrives as three stacks of fifty, not as one, so the number counts stacks
# rather than kinds and says nothing about delivery.
wait 8
ground 0
