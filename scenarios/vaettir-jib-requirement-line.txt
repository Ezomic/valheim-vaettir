# Vaettir: the crafting panel's chest total, in the format Robbin picked (LHM-28).
#
# At a bench served by a hod jib a requirement line now reads what you carry over what the
# recipe costs, then what the chests add in blue: "24/10 +169". This builds that bench, reads
# the lines the panel is really drawing for the Crude bow at x1 and at x5, measures whether
# each one fits its slot, then takes the leather out of the chest and checks that line goes
# back to the game's own plain number.
#
# FIRST RUN, 2026-09-28: every `panel` line read right, and both Wood `fits` failed at 12pt,
# "24/10 +169" needing 55.2 and "24/50 +169" 56.9 against 47.5. That 47.5 was res_amount's
# own rect, the part of the slot the game gave a bare number, centred in a slot 64 wide with no
# mask above it. The mod now widens the label to its slot and fits the line to that, so both
# should pass, at 13.9 and 13.5pt by the numbers above. The widening has not run in game.
#
# NEEDS: singleplayer, on a character whose pack you do not mind losing - `clear` destroys it.
# Stand on flat ground with about ten metres clear, away from other posts and chests. Keep the
# mouse pointer off the Craft button while it runs: the pointer leaving that button is the one
# thing that switches `multicraft` off behind the scenario's back.
#
# It also needs the new default format in your config. A file still on the old default,
# {need} <color=#88CCFF>(+{chest})</color>, is moved to the new one the first time this build
# loads, and own-profile's file was on the old one when this was written. So the first `panel`
# below is also the test of that move. If it fails and its note shows "10 (+169)", the move did
# not happen: [Internal] ConfigRevision should read 2 and [Hod] ChestTotalFormat
# {have}/{need} <color=#88CCFF>+{chest}</color>.
#
# THE NUMBERS. The Crude bow costs 10 wood and 8 leather scraps, and multi-craft makes that 50
# and 40. You carry 24 wood and 3 scraps, and the chest holds 169 wood and 57 scraps:
#
#               x1            x5
#   Wood        24/10 +169    24/50 +169
#   Leather     3/8 +57       3/40 +57
#
# `panel` and `fits` accept a label that CONTAINS the text, so the numbers are picked so that
# no likely wrong line contains the right one. What a broken build draws instead, each of which
# fails the `panel ... yes` checks:
#
#   the old format, or the move not run        "10 (+169)"
#   the pack counted with the chests in it     "193/10 +169" and "60/8 +57"
#   the cost left at x1 under multi-craft      "24/10 +169" where x5 wants "24/50 +169"
#   the chest count multiplied at x5           "24/50 +845"
#   the chest counted twice                    "24/10 +338" and "3/8 +114"
#
# The chest holds 57 scraps rather than 60 for the second of those: 3 carried plus 60 is 63,
# and "63/8 +60" contains "3/8 +60", so a pack count with the chests in it would have passed.
#
# A line cut off by its slot, or by a mask above it, fails `fits`, and the note gives the size
# it drew at, the width it needs, the room it has and how far any mask cuts. A `fits` that fails
# with 12pt in its note is the other case: the line was shrunk as far as it is allowed to go and
# the slot is still narrower. That is a question about the format, not a bug in the fitting, and
# the note says by how much.
#
# At x5 the grid slot holding your wood reads "24/50" too, which is why every x5 check keeps
# the "+169" on the end.
#
# AFTER THE LEATHER GOES the Leather slot should be the game's plain "8". What a broken build
# makes that read: one that writes the format with nothing in the chests draws "3/8 +0", and
# one that never puts the line back still draws "3/8 +57". Both contain "3/8", so `panel 3/8
# no` fails on either. It cannot prove the plain "8" itself, because the hotbar numbers on your
# inventory grid are labels reading "1" to "8" as well.
#
# THE RUN HOLDS FOR 45 SECONDS at the end with the panel open, the bow selected and the leather
# gone. Do these then. If the Devkit window covers the crafting panel, move it.
#
#   1. Wood slot. Expect "24/10" in the game's white and "+169" in light blue, all of it inside
#      the slot.
#   2. Hold Shift, the game's multi-craft key (AltPlace, if you rebound it). The Craft button
#      reads x5. Expect the Wood slot to read "24/50 +169", whole and readable, and the Leather
#      slot a plain "40". `multicraft` in the file sets the panel's own flag and never presses
#      the key, so this is the only check of the key itself.
#   3. Let go. Expect "24/10 +169" and "8" again.
#   4. Leather slot, throughout. Expect a plain number flashing red and white, because you carry
#      3 and the chest has none now. No slash and no blue part.
#
# AFTER THE RUN, in LogOutput.log. Both lines are written once per game session, so they are
# there after the first run since you started the game and not after a second one.
#
#   5. Search for "Hod requirement line, measured once". Expect one line, saying res_amount
#      was "widened to its slot from the game's 47.5". Send it to me if it says anything else.
#   6. Search for "too wide for its slot". Expect nothing. A line there means some line did not
#      fit even at size 12, and it names the widths.
#
# LEAVES BEHIND: the shed, the bench, the stowing post with its jib and the chest holding 169
# wood, all inside the patch the next jib scenario wipes. God and ghost mode stay on, as after
# every jib scenario. It takes defeated_eikthyr away again at the end so the test world is not
# left with Eikthyr down because of this file; if he really was down in that world, that is
# undone too. Devkit empties your pack and hands back its kit when the run ends, and switches
# multi-craft off if a step left it on.
#
# vaettir-jib-requirement-line-wide is the same bench with 769 wood in two chests and 124 in
# your pack, the widest line these numbers make.

clear
give Hammer:1,Hoe:1
give FineWood:250,BronzeNails:40,IronNails:52,Chain:4,GroveHeartwood:6
# LeatherScraps:1 so the character knows the material and the bow is in the panel at all.
# A recipe is only listed once every one of its materials has been carried.
give Wood:100,Stone:40,LeatherScraps:1
god
ghost

# The Meadows, found rather than promised, because a suite run starts wherever the scenario
# before it left you. On 2026-09-28 that was the Deep North, inside the Queen's entrance
# utangard-queen-door-stays-sealed spawns, and ten Vaettir files failed on the place and not
# on the mod: tilling refused as snow too deep, and the entrance's own pieces, cut through by
# `wipe`, falling and dropping copper scrap. Already in the Meadows, this does not move you.
biome Meadows
wait 3

sweep

wipe 16
wait 1

# Wood and leather scraps are Meadows materials, so Eikthyr has to be down for the chest to
# count at all. Taken away again at the end.
key defeated_eikthyr

flatten
wait 1

# The shed, so the bench can be crafted at. Captured from one built by hand.
place wood_beam 3.2 1.0 5 0.01
place wood_beam 3.4 -1.0 -174 0.00
place wood_floor 4.2 1.1 -174 0.02
place wood_floor 4.4 -0.9 -174 0.03
place wood_beam 4.1 2.1 -84 0.00
place wood_beam 4.5 -1.9 -84 0.03
place wood_beam 5.2 1.2 -174 0.00
place wood_beam 5.4 -0.8 -174 0.06
place piece_workbench 4.6 0.1 -174 0.10
place wood_pole2 3.1 2.0 5 1.04
place wood_pole2 3.5 -2.0 5 1.00
place woodwall 4.1 2.1 96 1.00
place woodwall 4.5 -1.9 -84 1.03
place woodwall 5.2 1.2 5 1.00
place woodwall 5.4 -0.8 5 1.06
place wood_pole2 5.1 2.2 5 1.01
place wood_pole2 5.5 -1.8 5 1.07
place wood_roof_ocorner_45 4.2 1.1 5 2.02
place wood_roof_ocorner_45 4.4 -0.9 -84 2.03
place wood_beam 4.1 2.1 95 2.00
place wood_beam 4.5 -1.9 -84 2.03
place wood_beam 5.2 1.2 5 2.00
place wood_beam 5.4 -0.8 5 2.06
place wood_beam_45 3.2 1.0 -174 3.01
place wood_beam_45 3.4 -1.0 6 3.00
wait 2

place stow_post 9 2
wait 6
place hod_jib 9 4
wait 4
place piece_chest_wood 7 3
wait 2

# 169 is the number from Robbin's screenshot: three digits after the plus.
stock piece_chest_wood Wood:169,LeatherScraps:57
holds piece_chest_wood Wood 169
holds piece_chest_wood LeatherScraps 57

# The pack: 24 wood and 3 scraps, counted by stack rather than through the game's CountItems,
# which the jib adds the chests to.
strip Wood,LeatherScraps
give Wood:24,LeatherScraps:3
carrying Wood 24
carrying LeatherScraps 3

goto piece_workbench
wait 1
use piece_workbench
wait 2

# 3 scraps carried against 8 needed, so this is yes only if the jib is counting the chest.
craftable Bow yes

select Bow
wait 1

# ---- x1

panel 24/10 +169 yes
panel 3/8 +57 yes
fits 24/10 +169
fits 3/8 +57

# ---- x5

multicraft on
wait 1

panel 24/50 +169 yes
panel 3/40 +57 yes
fits 24/50 +169
fits 3/40 +57

# ---- back to x1, exactly as before

multicraft off
wait 1

panel 24/10 +169 yes
panel 24/50 +169 no
panel 3/8 +57 yes

# ---- the leather goes, and its line with it

# `empty` takes everything, so the wood goes back in on its own.
empty piece_chest_wood
stock piece_chest_wood Wood:169
holds piece_chest_wood Wood 169
holds piece_chest_wood LeatherScraps 0

# The line counts this client's copy of each chest, which is refreshed once a second.
wait 2
select Bow
wait 1

# 3 carried and none in the chest: the jib has nothing to add.
craftable Bow no

# The wood line is still drawn in full, so the panel is drawing this recipe's lines right now
# and the leather line beside it is there to be read.
panel 24/10 +169 yes
panel 3/8 no

# ---- for your eyes: steps 1 to 4 in the header

wait 45

unkey defeated_eikthyr
close
